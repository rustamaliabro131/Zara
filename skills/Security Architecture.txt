WHY THE RETURN PATH IS MISSING
A microphone is a broadcast channel: anything within earshot can supply a
"spoken PIN", so a voice unlock is a lock screen with a public keypad on it.
The old path also drove simulated keystrokes (pyautogui) at the Windows lock
screen, which put the password on an input-injection route and in memory as a
string. The account password stays where Windows put it — with the user.
